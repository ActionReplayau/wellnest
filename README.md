# Wellnest

Our family's private daily health check-in. A web app that can be added to the home screen.

- The app's code lives here. **No health data is ever stored in this repository.**
- Entries are kept in the family's Supabase database, protected by its privacy rules.
- `js/config.js` holds the database address and its *publishable* key, which are safe to be public.
